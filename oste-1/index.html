Introdução à programação em R

Variáveis e condicionais

Objetivos da aula

  • Reconhecer o que é programação e seus benefícios na pesquisa científica.
  • Identificar variáveis de diferentes tipos em R: textuais, numéricas e lógicas.
  • Aplicar operações aritméticas e lógicas simples em R.
  • Usar o bloco if para controlar de fluxo de execução de programas R.

O que é programação?

  • Projetar, escrever, modificar e testar programas de computador.
  • Escrever um conjunto de instruções para que o computador possa executá-las passo a passo, como uma receita de bolo.
  • Em pesquisa ajuda a automatizar, documentar e compartilhar processos de manipulação de dados.

O que é uma linguagem de programação?

  • Uma linguagem artificial usada para expressar programas de computador.

R: o projeto de computação estatística

  • R é uma linguagem de programação e ambiente de desenvolvimento voltado à computação estatística e visualização de dados.

Um primeiro programa em R

print("Olá, mundo!")

Variáveis

  • Uma localização nomeada na memória do computador que guarda um valor, como uma caixa etiquetada.
  • Cada variável tem um tipo que depende do valor que ela guarda: texto, numérico, lógico, etc.
mensagem  <- "Olá, mundo!"

Variáveis textuais

  • Texto vai entre aspas duplas "..." ou simples '...'.
  • Variáveis textuais podem ser concatenadas com a função paste().
nome  <- 'Gui'

Variáveis numéricas

  • Guarda o valor de um número inteiro ou decimal.
nota_prova_1 <- 4.8

Operações aritméticas

  • Operadores aritméticos habituais para soma, subtração, multiplicação, divisão e potenciação.
nota_prova_1 + nota_prova_2

Variáveis lógicas

  • Assumem os valores TRUE ou FALSE.
  • Expressões de comparação resultam em valores lógicos.
idade >= 18

Variáveis lógicas

  • É possível combinar expressões lógicas simples para formar expressões complexas usando operadores lógicos de negação (not), conjunção (and) e disjunção (or).
idade >= 18 & assinou_consentimento

Controlo de fluxo: if

  • O if executa um bloco de instruções só quando uma condição é verdadeira.
  • Opcionalmente adiciona-se um bloco sob a palavra-chave else para o caso contrário.
escore <- 28
if (escore >= 26) {
  grupo <- "elevado"
} else {
  grupo <- "não elevado"
}
