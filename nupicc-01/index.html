Aprendizagem supervisionada

Dado um conjunto de n pares entrada–saída

{(x1, y1), (x2, y2), …, (xn, yn)}

gerados por uma função desconhecida y = f(x),

descubra uma função h que aproxima f.

Exemplo - Rastreio de depressão com o PHQ-9

2(0, 1, 0, 0, 1, 0, 0, 1, 0)não
3(2, 3, 2, 3, 3, 2, 3, 2, 3)sim
⋮⋮⋮
n(1, 0, 1, 0, 0, 1, 0, 1, 0)não

Aprendizagem supervisionada

  • h é a hipótese escolhida de um espaço de hipóteses H (todas as retas, todas os polinômios de grau 2, todas as árvores de decisão com profundidade 5).
  • x é o vetor de atributos da entrada (idade, escores em escalas, exames laboratoriais, …).
  • y é o saída, o valor que queremos predizer.

Diferentes espaços de hipóteses

Fonte: Russell, S. e Norvig, P. (2021). Artificial Intelligence: A Modern Approach, 4ª ed.

Viés e variância

Propriedades associadas aos espaços de hipóteses.

Viés (bias)

Tendência de desviar sistematicamente do valor esperado.

  • Alto viés: as hipóteses são simples demais para capturar a relação real.

Variância

O quanto as hipóteses mudam em resposta a mudanças nos dados de treinamento.

  • Alta variância: as hipóteses são bastante sensíveis a flutuações nos dados.

Subajuste e sobreajuste

Subajuste (underfitting)

  • O modelo é simples demais e não consegue capturar os padrões presentes nos dados.
  • Desempenho ruim tanto nos dados de treinamento quanto em dados novos.

Sobreajuste (overfitting)

  • O modelo é complexo demais e "decora" os dados de treinamento, incluindo o ruído.
  • Bom desempenho no treinamento, mas ruim em dados novos.

Árvore

Árvores de decisão

  • Uma função que mapeia um vetor de atributos para uma saída única, a decisão
  • O mapeamento é feito por meio de uma série de perguntas organizadas em estrutura de árvore.
  • Nó: um teste sobre um atributo (escore no item 4 do PHQ-9 > 2?).
  • Ramo: uma resposta possível (sim ou não).
  • Folha: a decisão final (apresenta o transtorno ou não).

Exemplo - Rastreio de depressão com o PHQ-9

Como o computador constrói a árvore?

Usa uma estratégia de dividir para conquistar que é gulosa

  1. Qual a pergunta que melhor separa as observações?
  2. Essa pergunta vira a raiz da árvore e as observações são divididas de acordo com a resposta.
  3. Repete recursivamente em cada subgrupo de observações até as folhas ficarem totalmente homogêneas (ou as perguntas possíveis acabarem).

Como saber qual a melhor pergunta para dividir?

O critério mais usado mede o ganho de informação: favorece perguntas que geram subgrupos mais homogêneos.

Vantagens e limitações

Vantagens

  • Facilmente interpretável.
  • Opera com atributos categóricos e numéricos.
  • Realiza tarefas de classificação e regressão.

Limitações

  • Alta variância.
  • Tendem ao sobreajuste se não forem podadas.

Treino, validação, teste

  • Treino ajusta os parâmetros do hipótese.
  • Validação compara hipóteses candidatas e ajusta hiperparâmetros.
  • Teste gera uma estimativa de desempenho da hipótese final.

Se você usa o conjunto de teste para selecionar as hipóteses candidatas, ele deixa de ser um teste válido.

Treino, validação, teste

Fonte: Russell, S. e Norvig, P. (2021). Artificial Intelligence: A Modern Approach, 4ª ed.

Validação cruzada k-fold (k-fold cross-validation)

E se eu não tenho dados suficientes para separar três conjuntos grandes?

  1. Divida os dados em k partes iguais (5 ou 10 são típicos).
  2. Treine em k−1 partes; valide na que sobrou.
  3. Repita k vezes, alterando qual parte fica de fora.
  4. Reporte a média dos k resultados de validação.

Quando k = n chamamos de leave-one-out cross-validation (LOOCV).

Regularização

  • Algumas hipóteses perdem poder de generalização conforme ficam mais complexas.
  • Uma opção é aplicar técnicas de regularização: uma penalização à complexidade da hipótese.
  • Em uma árvore de decisão podemos limitar a profundidade máxima da árvore ou o número de nós.

Parâmetros e hiperparâmetros

Parâmetros

  • Aprendidos a partir dos dados.
  • São o resultado do treinamento.
  • Ex.: coeficientes de uma regressão; pesos de uma rede; cortes nos nós de uma árvore.

Hiperparâmetros

  • Configuram do processo de treinamento.
  • Escolhidos pelo pesquisador antes do treinamento.
  • Ex.: profundidade máxima da árvore; k em k-fold; taxa de aprendizado; força da regularização.

Ensemble learning

  • Em vez de uma hipótese, treinamos várias e combinamos suas previsões (voto majoritário ou média).
  • Essa combinação reduz viês e variância.
  • Quatro famílias principais: bagging, random forest, stacking, boosting.

Bagging

  1. Sorteie, com reposição, do conjunto de dados de treinamento, k amostras do mesmo tamanho.
  2. Treine um modelo base em cada amostra.
  3. Para fazer predições: use voto majoritário (classificação) ou média (regressão) das previsões dos k modelos base.

Random forest

  • Uma extensão do bagging para árvores de decisão.
  • Um atributo for muito informativo tende a ser a raiz em quase todas as árvores em um ensemble de bagging.
  • Uma solução é considerar apenas um subconjunto aleatório dos atributos em cada divisão da árvore.

Stacking

Em vez de combinar modelos do mesmo tipo (como em bagging), o stacking combina modelos de tipos diferentes.

  1. Treine vários modelos base nos dados de treino (uma regressão logística, uma árvore, uma SVM).
  2. Use o conjunto de dados de validação para obter as previsões de cada modelo base.
  3. Treine um meta-modelo que aprende a combinar as previsões dos modelos base.

Boosting

  1. Treine o modelo 1 nos dados com pesos iguais para cada observação.
  2. Identifique os exemplos que o modelo 1 errou; aumente o peso deles.
  3. Treine o modelo 2 nessa amostra reponderada; ele é "forçado" a se preocupar com as observações difíceis.
  4. Repita por k rodadas; a predição final é um voto ponderado dos k modelos.

Boosting

Fonte: Russell, S. e Norvig, P. (2021). Artificial Intelligence: A Modern Approach, 4ª ed.

Gradient boosting

Variação do boosting onde, em vez de aumentar o peso das observações erradas, o próximo modelo é treinado com foco no gradiente de erros residuais produzidos por modelos anteriores.

Deep learning

  • Família de técnicas que usam circuitos algébricos com muitos níveis e cujas conexões têm pesos ajustáveis.
  • Inspiradas em modelos que buscavam reproduzir o funcionamento de neurônios biológicos; redes neurais artificiais.
  • Lida muito bem com dados de alta dimensionalidade e padrões complexos de interação entre variáveis.

Deep learning

Fonte: Russell, S. e Norvig, P. (2021). Artificial Intelligence: A Modern Approach, 4ª ed.

Anatomia de um neurônio artificial

Cada unidade (neurônio artificial) faz duas operações:

  1. Soma ponderada das entradas: in = w1x1 + w2x2 + … + b
  2. Função de ativação não linear: saída = g(in)

Os pesos wi e bias b são os parâmetros que o treino vai ajustar.
